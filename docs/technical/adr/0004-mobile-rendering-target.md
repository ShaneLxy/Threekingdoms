# ADR-0004：采用 Mobile（Vulkan）作为 Android 默认渲染路径

**状态**：已接受  
**日期**：2026-07-12  
**引擎基线**：Godot `4.7.stable.official.5b4e0cb0f`

## 背景

本项目是横屏 2D 像素风割草游戏，需要在手机上承载大量敌军表现、预警、VFX 与较长战斗时长。Godot 4.7 提供 Mobile（Vulkan）和 Compatibility 等渲染路径；若不先定义主路径，性能设计、资源表现与真机验收会失去共同基准。

## 决定

- 默认使用 Godot 4.7 的 **Mobile 渲染器（Vulkan）**。
- 逻辑画布使用横屏 16:9、1280 × 720，后续按设备缩放并保留 UI 安全边距。
- 参考设备档：Snapdragon 778G / Dimensity 1080、6 GB 内存、Android 11+，以 60 FPS 为目标。
- 最低兼容档：Snapdragon 720G / 同等级 Vulkan 设备、4 GB 内存、Android 10+，以 30 FPS 为目标。
- Compatibility 渲染器不作为首个版本的默认或并行维护路径；只有最低兼容档出现无法接受的 Vulkan 驱动问题时，才单独立项评估。

## 后果

### 正面

- 团队可围绕一个现代移动端渲染路径定义性能预算与资源规范。
- 参考档能验证 60 FPS 兵海表现，最低兼容档确保设计有明确降级边界。
- 逻辑画布稳定，有利于像素风图集、战斗距离和 UI 布局保持一致。

### 负面

- 不承诺覆盖不支持 Vulkan 或驱动质量很差的旧设备。
- 必须尽早取得两档真机进行压测，不能只依赖 Windows 编辑器。
- 若未来加入 Compatibility，需要额外验证 Shader、材质、批量渲染和画面差异。

## 关联需求

TR-001、TR-003、TR-005、TR-008、TR-010。

## 引擎兼容性

决定针对已确认的 Godot 4.7 稳定版。创建 `project.godot` 时必须将默认渲染方法设为 Mobile，并在两档 Android 真机上验证导出、触摸输入、2D 批量渲染和像素缩放。
