# 博望坡曹军将领

> 状态：首轮可玩原型。数值为当前测试起点，后续按真机数据调整。

## 设计目标

- 高级敌人必须有成体系的连招和独立冷却，不能依固定顺序无间隔施放技能。
- 普攻使用橙色预警并允许普攻拼刀；主动位移/阵型招式使用紫色预警并允许主动技能拼刀。
- 所有位移均为可见平移；攻击方向在前摇开始时锁定。

## 夏侯兰

- 武器与定位：长枪、游斗型精英。
- 移动：常规步行接近，在攻击时只使用左右横向枪术；不瞬移、不连续侧跳。
- 连招：`试探刺 -> 横枪扫 -> 试探刺`，三段均提供清晰的普攻拼刀窗口。
- 特殊技能：`斥候追刺`。预警后沿水平路线进行一次短距离可见突进，以主动技能拼刀应对；单独冷却约 `5.8s`。
- 区分：不使用张郃式多方向长刺与连续机动，主要负责给轻骑和枪阵创造短暂追击压力。

## 韩浩

- 武器与定位：大盾、短刀，推进型精英。
- 移动：低速正常步行，稳定站在盾兵、枪兵和弩兵构成的前排。
- 连招：`盾击 -> 横斩`。距离短但击退和压迫明显，两段均可普攻拼刀。
- 特殊技能：`盾阵前压`。预警后举盾水平平移约 `0.72s`，结束后进入较长恢复；以主动技能拼刀应对，独立冷却约 `6.6s`。
- 区分：不是高伤大范围斩击，而是把玩家向枪弩火力与火线方向挤压。

## 夏侯惇

- 武器与定位：重枪、正面推进型 Boss。
- 移动：低速步行调整纵向位置，再以横向攻击面对英雄；只有 `冲阵` 会进行可见的水平平移。
- 普攻连招：`督军横扫 -> 重枪突刺` 与 `横扫 -> 横扫 -> 突刺` 两套连招，前摇锁定方向，提供普攻拼刀窗口。
- 特殊技能一：`冲阵`。紫色预警后进行一次短距离平移冲锋，可由英雄主动技能拼刀，独立冷却约 `7.8s`。
- 特殊技能二：`火谷合围`。二阶段起在玩家上下两侧各布置一条长火线，中间保留稳定安全带；火线以紫色技能预警，独立冷却约 `9.6s`。
- 阶段：与现有 Boss 共用阶段、架势、破势、受击打断和护卫逻辑；第二、三阶段提高招式衔接频率，而非无条件提高所有动作速度。
