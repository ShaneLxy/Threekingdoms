# 《三国：破阵斩将》游戏设计文档

> 状态：设计草案 v0.1  
> 最后更新：2026-07-12  
> 阶段：玩法设计，尚未进入代码实现。

## 项目定位

一款以三国名将为核心、在兵海中破阵斩将的俯视斜角 2D 像素 Roguelike 手游。

体验支柱：

1. **兵海压迫**：敌军从四面推进，持续要求玩家移动、破围与判断危险区。
2. **名将爽感**：每名武将拥有鲜明兵器、连招、主动技能与无双演出。
3. **军阵策略**：兵种、阵型和敌将技能相互组合；破阵比单纯堆伤害更重要。
