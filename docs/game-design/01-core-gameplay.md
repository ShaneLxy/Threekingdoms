# 核心玩法

> 状态：草案 v0.1

## 一句话定位

以三国名将为核心、在兵海中破阵斩将的俯视斜角 2D 像素 Roguelike 手游。

## 已定设计原则

- 画面与战斗采用横屏、俯视斜角 2D 视角；不是横版卷轴。
- 玩家手动移动、手动攻击；**不采用常规自动攻击**。
- 普攻与主动技能采用“出招承诺”：前摇、命中帧、后摇期间锁定常规移动与朝向；只有第三段突刺、主动技能和无双等招式自带的位移可以移动。
- 每次普攻允许缓存一段下一次输入；小兵受击会短硬直与击退，并以短暂停帧、闪白、枪影和微震确认命中。
- 每名英雄固定拥有：一项被动、一项主动技能、一项无双技能。
- 首个版本不设置独立闪避键；移动、普攻位移、主动技能与无双共同承担脱围职责。
- 每局在一张有清晰边界的开放战场中持续战斗；剧情通过时间线、敌军组合和事件推进，不切换为多个闯关区域。
- 战斗核心是“破阵、走位、斩将”，而不是站桩堆叠自动伤害。

## 单局核心循环

```text
移动走位
→ 主动攻击
→ 击杀敌兵
→ 获得经验
→ 升级时三选一局内强化
→ 应对精英军阵 / 敌将
→ Boss 战
→ 结算奖励
```

## 资源定义

| 资源 | 取得方式 | 用途 | 生命周期 |
|---|---|---|---|
| 经验 | 击杀、经验掉落物、关卡事件 | 局内升级，触发三选一强化 | 单局 |
| 军功 | 关卡结算、任务、剧情目标 | 解锁武将、局外天赋、初始兵器或剧情节点 | 局外 |
| 无双能量 | 战斗行为与特定掉落 | 释放无双技能 | 单局战斗中 |

## 基础操控方案

| 输入 | 功能 | 设计目的 |
|---|---|---|
| 左侧虚拟摇杆 | 移动 | 保证兵海中持续走位与拉扯。 |
| 右侧攻击区 | 拖拽确定方向，手动释放普攻连段 | 保留名将兵器操作感；提供轻度方向辅助而非自动出手。 |
| 主动技能键 | 释放英雄主动技能 | 用于破阵、脱围或关键爆发。 |
| 无双技能键 | 无双能量满时释放 | 制造一局中的高光时刻。 |

无双能量条必须常驻显示；充满时能量条和按钮高亮、角色出现光环并显示“无双已就绪”。未充满时尝试释放需明确提示当前能量。

## 局内强化与局外天赋

### 局内强化池

局内强化池是玩家升级时随机抽取三项、选择一项的候选集合。它服务于本局构筑，不会永久保留。

来源类别：

- 武器与普攻强化。
- 被动技能强化。
- 主动技能强化。
- 无双技能强化。
- 通用战斗强化。

### 局外天赋

局外天赋是使用军功解锁的永久成长或内容解锁，例如新武将、初始能力、小幅基础属性或剧情节点。局外天赋不应替代局内构筑选择。

## 首个可玩版本边界

首个垂直切片只验证以下内容：

- 赵云一名可玩武将。
- 刀兵、戟兵、弓兵、盾兵四种基础敌兵。
- 一张长坂坡主题地图。
- 一局 10 分钟剧情关卡。
- 夏侯恩、淳于导两名具名精英与一名敌将 Boss。
- 赵云初版 12 项局内强化。

不在首个版本中验证的内容：多武将、多章节、复杂局外养成、联网、完整无尽模式结算。
