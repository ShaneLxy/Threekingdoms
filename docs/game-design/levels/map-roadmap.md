# 战场地图路线图

> 状态：路线图 v0.2  
> 目的：在长坂坡之外建立具有明确空间与兵种差异的战场内容；博望坡已进入首轮可玩原型，其余地图仍待原型验证。

## 共同设计约束

- 地图差异必须同时体现在活动空间、刷怪入口、敌军编组和环境压力，不能只替换背景素材。
- 在敌军完整避让与导航系统成熟前，优先使用软地形：可视化分区、不可生成区、刷怪通道和环境危险区；不以大量硬障碍阻断单位移动。
- 新地图首发只引入一至两种新兵种，先验证其与现有刀、盾、戟、弓的组合价值，再继续扩充。

## 1. 博望坡·火谷

| 项目 | 大纲 |
|---|---|
| 状态 | 已接入首轮可玩原型，剧情模式在完成长坂坡后开放。 |
| 空间 | `2304 x 1248` 的偏狭山谷；代码占位地形以石道、焦土、坡脚和燃烧林带构成纵向推进感。 |
| 核心体验 | 魏军以盾兵、枪兵、弩兵和军旗兵组成正面军阵；玩家在明确的横向攻击窗口与安全带中破阵。 |
| 环境 | 可读的余烬、焦土与火谷地形不遮挡角色和攻击预警。夏侯惇二阶段会施放两条留有中间安全带的火线。 |
| 精英 | 夏侯兰：三段横向枪术，拥有一次可拼刀的短距离横向追刺。韩浩：盾击、横斩和可拼刀的盾阵前压。 |
| Boss | 夏侯惇：重型横向三连、可见的短距离冲阵，以及火谷合围；与张郃的高速枪术形成区分。 |
| 剧情时序 | `126s` 夏侯兰，`292s` 韩浩，`438s` 夏侯惇。精英在 Boss 前以独立战斗段落出现，不要求三名高级敌人长期同场。 |
| 待验证 | 火线伤害、Boss 阶段转化与盾阵推进在真机上的压力是否恰当；正式像素素材接入后的角色可读性。 |

## 2. 官渡·乌巢

| 项目 | 大纲 |
|---|---|
| 空间 | 较开阔的夜间粮营，营帐、辎重车与粮垛划分战场区域，但不作为硬阻路墙。 |
| 核心体验 | 多方向兵潮与后排威胁并存，玩家需要判断切入点并优先斩杀支援目标。 |
| 环境 | 火把、粮草火光和夜雾构成层次；敌军出生与增援从营门、粮道等明确入口进入。 |
| 新兵种优先级 | 弩兵：蓄力后的扇形连弩齐射，射击后有明显装填空档。 |
| 后续候选 | 军旗兵：为附近杂兵提供有限增益，形成可识别的优先击杀目标。 |

## 3. 虎牢关外·斗将台

| 项目 | 大纲 |
|---|---|
| 空间 | 约一个半屏的紧凑方形战场，边界清楚，保留少量护卫的回旋空间。 |
| 核心体验 | 聚焦精英/Boss 连招、拼刀、破势和构筑验证，而非大规模杂兵生存。 |
| 环境 | 关隘石台、军旗、鼓阵与远处兵海作为氛围，不干扰攻击预警和角色识别。 |
| 敌军 | 精英、Boss 与少量护卫；可复用名将斗阵的刷怪约束。 |
| 待验证 | 是否作为独立剧情章节 Boss 场，或作为多个名将共享的试炼场变体。 |

## 推荐制作顺序

1. 博望坡·火谷：首轮战斗与占位表现已接入，待真机平衡与正式素材。
2. 官渡·乌巢 + 弩兵。
3. 虎牢关外·斗将台。

每一阶段完成后均应在真机验证：敌军可读性、环境提示、帧率、温度和新增兵种是否创造了新的决策。
