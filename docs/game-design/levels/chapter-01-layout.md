# 第一章战场布局：长坂坡·单骑救主

> 状态：关卡空间草案 v0.2  
> 对应关卡：[第一章：长坂坡·单骑救主](chapter-01-changban.md)  
> 核心规则：一张有明确边界的开放战场。剧情只改变敌军、事件和场景状态，不切换战区。

## 一、关卡形态

本关是一张中小型的开放战场，而不是街机式“打一段、走到下一段”的多区域关卡。

- 玩家从开局到结算始终在同一张长坂坡战场内战斗。
- 10 分钟内通过敌军兵种、出生方向、军阵、Boss 与环境状态变化推进剧情。
- 地图存在明确边界，避免玩家无目的跑图；边界外的雪坡、断桥、残墙和营垒只承担世界观与封闭作用。
- 战场中央保持开阔，边缘景物不形成卡死角；挑战来自敌军围困与预警，而非地形迷宫。

这种结构更贴近经典纯割草 Roguelike：玩家的注意力始终放在走位、清兵、升级和破阵上，而非赶路或过场。

## 二、整体尺寸与平面布局

使用“兵位”描述空间：1 兵位约等于一名普通敌兵的碰撞直径。

- 有效战斗区域：约 **32 × 22 兵位**。
- 镜头可见区域：约占战场的 55% 至 65%；镜头随玩家移动，靠近边界时平滑夹紧。
- 中央主战场：约 16 × 12 兵位，完全无硬碰撞装饰。
- 外围缓冲环：宽 4 至 6 兵位，用于拉怪、横移躲避与敌军绕入。

```text
北：断桥与魏军旗阵（主出生区）
┌──────────────────────────────────────────┐
│   N1 盾戟主阵      [断桥 / 残旗]      N2  │
│                                            │
│ W1 残墙雪坡   ┌────────────────┐  东侧营垒 E1 │
│               │   中央石坪     │              │
│               │  无硬碰撞主场  │              │
│               └────────────────┘              │
│ W2 断车残骸      南侧缓冲带 / 开场点       E2 │
│                                            │
│ 南：刘备军残营与雪坡（无近距离伏兵）          │
└──────────────────────────────────────────┘
```

## 三、边界与可移动空间规则

| 项目 | 规则 | 目的 |
|---|---|---|
| 北侧边界 | 断桥、旗阵和不可通行深雪构成弧形边界 | 提供魏军主攻方向与 Boss 出场位置。 |
| 东西边界 | 残墙、营垒和雪坡组成平滑外缘 | 视觉上封闭地图，但不制造直角死角。 |
| 南侧边界 | 刘备军残营、坡底雾区 | 作为玩家初始缓冲方向，前中期不生成近距离伏兵。 |
| 中央区域 | 不放置有碰撞的火盆、旗杆、石块 | 确保兵海中始终有可用绕圈空间。 |
| 边缘可通行带 | 宽度至少 4 兵位 | 允许玩家沿边缘拉怪，但不鼓励无限绕圈。 |
| 红圈安全规则 | 同时覆盖面积不超过可移动区域的 40% | 无闪避键时，必须让玩家看得见并走得到安全区。 |

地图边界本身不能成为“盾兵顶住 + 墙体卡位 + 红圈落下”的无解陷阱。若敌军将玩家推近边缘，至少应保留一条横向移动通路，或由赵云的第三段/主动技能穿出。

## 四、出生点与军阵锚点

| 锚点 | 默认兵种 | 使用时机 | 空间作用 |
|---|---|---|---|
| N1 / N2 北侧 | 刀兵、盾兵、戟兵、Boss | 全程主压力；8 分钟后为 Boss 与护卫入口 | 形成正面主阵线。 |
| W1 西北残墙 | 弓兵、少量戟兵 | 1:20 后 | 制造横向箭矢威胁。 |
| E1 东北营垒 | 弓兵、刀兵 | 1:20 后 | 与 W1 交替施压，避免两侧同时封死。 |
| W2 西南断车 | 刀兵、少量追兵 | 中后期 | 限制玩家只沿南侧绕圈。 |
| E2 东南雪坡 | 刀兵、戟兵 | 中后期 | 与 W2 轮换形成夹击。 |

### 出生规则

- 敌人从镜头外缘、残墙后或营垒后进入；不在玩家脚边、经验包旁或镜头中心突然生成。
- 同一时刻最多两个方向承担主要压力；第三方向只能是低密度追击或远程骚扰。
- 弓兵箭雨与 Boss 大范围预警不可同时封锁所有外圈通路。
- 北侧始终是主攻方向，南侧始终保有较低压力，使玩家能通过“向南拉开、向侧方切入”重整阵线。

## 五、时间线在同一战场中的变化

| 时间 | 战场状态 | 敌军空间组织 | 场景 / 剧情变化 |
|---|---|---|---|

| 1:20–2:50 | 乱箭逼近 | W1、E1 轮流出现弓兵；北侧刀兵压迫 | 断墙后点亮火把，箭矢预警首次出现。 |
| 2:50–4:20 | 拒阵 | 北侧盾兵居前、弓兵居后；一侧戟兵斜向推进 | 魏军旗阵更密集，中央石坪仍保持可绕行。 |
| 4:20–5:20 | 偃月拦路 | 夏侯恩自北侧进入，两翼各有小股戟兵 | 北侧旗阵短暂拉开，突出精英出场与攻击预警。 |

## 六、关键军阵的空间设计

### 盾弓阵

- 位置：北侧偏中，向中央石坪缓慢推进。
- 组成：前排 3 至 5 名盾兵，后排 2 至 3 名弓兵；两侧保留至少一条 5 兵位宽的绕行空隙。
- 破法：玩家可从侧翼绕入切弓兵，或以赵云第三段 / 七探盘蛇直穿盾线。
- 禁止：盾兵、墙体和箭雨不能同时闭合为完整半圆。

### 戟卫夹击

- 位置：东、西两侧交替出现，不同时从两边高密度压入。
- 组成：每侧 2 至 3 名戟兵配少量刀兵。
- 破法：向未施压的一侧横移，利用点刺处理戟兵前摇，或以主动技能穿过薄弱侧。
- 禁止：戟兵长刺预警不可覆盖南侧缓冲区。

### 完整军阵（6:50–8:15）

- 北侧盾弓阵是主压迫；东/西戟卫只是阶段性收紧，不承担永久封锁。
- 赵云可以先向南拉直兵线，再选择东或西侧切入；无双用于从侧翼穿过后排并回到南侧。
- 该阶段应形成“危险但有解”的兵海，而不是要求玩家持有某一张特定强化才能存活。

## 七、Boss 场地：张郃

完整阶段、招式时序和数值见[Boss：张郃](../bosses/zhang-he.md)。

Boss 战仍发生在同一张战场，不切换专用小房间。

- 张郃在北侧主阵入口出现，初始站位在中央石坪偏北。
- 南侧缓冲带始终可用；Boss 不会将玩家推入封闭墙角。
- “枪刃横扫”只覆盖一个扇面，外圈与另一侧必定存在安全区。
- “雁翎突刺”沿直线穿过中央，东西两侧均允许横移躲避。
- “雁阵号令”一次只从东或西一侧补入护卫，并与 Boss 大范围预警错开释放。
- Boss 倒下后立即停止刷怪，避免胜利已定却被残余兵海拖延结算。

## 八、镜头与美术层级

### 镜头

- 俯视斜角横屏，角色位于画面中心略偏下，北侧主攻方向拥有更大观察空间。
- 镜头在地图边缘平滑夹紧，不突然移位；不会为剧情切换加载或转场。
- 精英 / Boss 出场只允许短暂轻推镜，战斗输入不冻结。

### 美术层级

1. **可战斗地面**：灰蓝石道与雪地，低对比、无复杂纹理，保证预警清晰。
2. **战斗对象**：赵云、敌军、经验包、技能与红圈，拥有最高对比和轮廓。
3. **边界叙事物**：断桥、营帐、残墙、旗阵、火盆，集中放在地图边缘并减少硬碰撞。

## 九、原型制作顺序

1. 先搭建 32 × 22 兵位的矩形可移动区域与平滑边界。
2. 用 6 个颜色锚点模拟 N1、N2、W1、E1、W2、E2 出生位置。
3. 依时间线加入刀兵、弓兵、盾兵、戟兵、精英与 Boss；先不制作剧情演出。
4. 验证无闪避键下的空间安全、兵阵破法和无双使用时机。
5. 验证通过后，再替换为长坂坡像素场景、雪夜光照、残旗与烽火效果。

## 十、布局验收标准

1. 玩家从开局到 Boss 始终在一张有边界的地图内，不发生区域切换或赶路流程。
2. 地图足够小，玩家能在短时间内从中心抵达任一边界；又足够大，能容纳兵海与多方向压力。
3. 任何阶段都有可读的安全区和至少一条脱围路线；无闪避键不会导致无解死亡。
4. 时间、敌军方向、军阵和环境变化能清晰表现剧情推进，即使地图不更换也不会显得单调。
5. 出生点与敌军表现数量可以受性能预算控制，且不破坏关卡的空间意图。
