# 移动端 UI/UX 规范

> 状态：MVP 决定版 v0.1  
> 适用范围：横屏 16:9、Godot 4.7、赵云首个可玩演示。

## 1. 已锁定交互

- 左下虚拟摇杆负责移动；右下为普攻、主动、无双。
- 普攻按下即出招；攻击按钮不指定方向，始终沿英雄当前左右面朝发动。长按不产生自动连续攻击。
- 主动技能沿当前左右面朝释放；移动摇杆的左右输入负责改变面朝。
- 无双开启后每一段突进均由左摇杆决定 8 向路径；摇杆中立时沿上一段方向继续。
- 首个版本没有独立闪避键；红圈、军阵和 Boss 招式必须留出可走到的安全区。

## 2. HUD 信息层级

```text
┌ 暂停  等级/经验 ───────── 剧情提示 ─────── 计时 ┐
│                  有边界开放战场                  │
│                                                  │
│ [移动摇杆]                        [普攻] [主动]  │
│                                         [无双]   │
└──────────────────────────────────────────────────┘
```

| 区域 | 内容 | 规则 |
|---|---|---|
| 顶部左侧 | 生命、等级、经验 | 常驻，但不遮挡中央战场。 |
| 顶部中间 | 剧情/阶段提示 | 短文本自动淡出；不使用长对话框。 |
| 顶部右侧 | 计时、暂停 | 保持与战场信息分离。 |
| 顶部下方 | 敌将状态栏 | Boss 使用近满宽主栏；精英使用下方固定槽位。 |
| 左下 | 摇杆触控区 | 至少占屏幕宽度 28%，允许拖拽超出圆环。 |
| 右下 | 普攻、主动、无双 | 普攻最大；无双不足 40 时显示当前能量，达到 40 后金色呼吸高亮。 |

- 左上生命条下方常驻“无双 n / 100”能量条，不能只依赖右下的小百分比。
- 无双能量上限为 100、每次消耗 40。能量首次达到 40 时，中央显示“无双已就绪”，右下按键出现可释放标记，赵云身上出现持续光环；能量不足时点击按键应短暂显示“能量不足”。

## 3. 安全区与适配

- 逻辑画布为 1280 × 720，横屏 16:9。
- HUD 与交互按钮距屏幕边缘至少 4% 宽度；实际设备的刘海、圆角和系统手势区额外避让。
- 战斗关键预警不能出现在顶部 HUD 下方的不可见区域；触控按钮周围不放置关键拾取物或敌军血条。
- 小兵、精英和 Boss 均不在单位头顶显示生命条；玩家生命显示在左上，精英与 Boss 生命统一显示在顶部敌将状态栏，单位自身只保留短暂受击与“破绽”等即时反馈。
- 战场世界不使用调试阶段的黑色外边框；画面由连续地面铺满，边界通过后续的崖壁、军营、栅栏等世界内地形表达。
- 战斗镜头以英雄为中心跟随，初版缩放为 1.55；当前左右面朝可提供轻微前探，镜头在战场边界自动限制，不得露出世界外区域。
- 长坂坡原型战场为 1920 × 860，常规敌军优先生成在镜头外 480–610 世界单位处；地图扩大不能导致敌人从全局边缘赶路而使战斗空档变长。
- HUD 位于独立 UI 层，必须固定在屏幕上，不能因镜头移动或缩放而漂移。

### 敌将状态栏

- Boss 活跃时占顶部第一优先级，使用约 90% 安全宽度的一条主栏；精英在其下方使用最多两列两行的固定槽位。
- 无 Boss 时，一名精英居中显示；两名及以上改为双列。槽位按登场顺序固定，不因距离或受击反复换位。
- 具名精英同时最多显示四名；战斗设计也应避免第五名作为可攻击威胁同时登场。
- 同一单位只有一个物理血条框。精英暂以 65 HP 为一管、Boss 暂以 500 HP 为一管；多个生命管用不同颜色的内嵌层叠显示，不新增第二行血条。
- 生命条使用即时前景与延迟损血残影，Boss 另显示阶段刻度。精英/Boss 离场时状态栏收拢淡出。

## 4. 视觉语言

- 战斗 UI 使用青黑半透明底色、暗金边框与古纹角线；避免大面积高亮遮挡战场。
- 赵云、技能可用与能量信息使用青蓝/银白；无双可用使用暗金；敌方危险与 Boss 使用朱红。
- 面板与按钮以可伸缩的代码绘制和主题样式构成，所有文字、数值与冷却状态必须是动态内容，不能烧录在贴图内。
- 三选一卡和结算窗口沿用同一套暗金面板、悬停青蓝描边、按下金色描边，保证战斗内外一致。

### 敌将比例与表现层级

- 杂兵与赵云的身体高度以 1.00 为基准；精英约为 1.05，Boss 约为 1.10，任何敌将的躯干不得超过普通单位的 1.15。武器、披风和气势可超出身体轮廓，但脚底锚点必须一致。
- 精英以紧贴身体的暗红/土橙色不规则像素碎片区分；张郃以枪杆周围的紫蓝、暗金枪势碎片区分。常驻效果不得使用完整红橙地面圆环，以免与伤害预警混淆。
- 战场绘制顺序固定为：地面与预警 → 杂兵 → 精英与其气势 → Boss 与其气势 → 赵云与赵云技能 → HUD。这样敌将不会被兵海遮挡，赵云也不会被敌将身体压住。

## 5. 输入优先级

1. 升级三选一、暂停、结算等模态界面拦截战斗输入。
2. 主动与无双输入优先于同一触点的普攻输入。
3. 普攻输入进入一次连招缓存；动画前后摇不能吞掉下一段合法输入，但当前招式不能被任意取消。
4. 方向辅助最多修正到附近目标，不能替玩家自动攻击或跨屏锁定。

## 6. 三选一

- 升级时暂停局内模拟，保留背景战场但降低视觉亮度。
- 屏幕中部显示三张大卡，每张包含名称、短效果和简单图标/色条。
- 首个 MVP 不提供重掷；触碰卡片即确认，确认后恢复战斗。
- 选择内容以赵云的 12 项局内强化池为准。

## 7. 结算与重开

- 胜利、失败或时间耗尽后，战斗输入停止并显示局内结算遮罩。
- 结算遮罩必须提供大尺寸“重新开始”按钮；点击后重载本局，玩家不应需要关闭应用才能再次挑战。

## 8. 前 30 秒无文字教学

| 时间 | 画面/行为 | 希望玩家理解 |
|---|---|---|
| 0–5 秒 | 左下摇杆轻微呼吸，北侧少量刀兵接近 | 移动。 |
| 5–15 秒 | 普攻按钮高亮，刀兵进入点刺距离 | 手动攻击与方向。 |
| 15–25 秒 | 首批经验包落地并有短光线引导 | 接近拾取经验。 |
| 25–30 秒 | 升级面板弹出 | 三选一构筑。 |

## 9. MVP 占位表现范围

首个可试玩版本使用代码绘制的色块、轮廓、预警与文字代替最终像素资源：赵云为蓝白轮廓，魏军为深灰/赤色轮廓，红橙色表示危险区。这样先验证手感与可读性，正式像素资产在玩法稳定后替换。
