# 英雄设计：张飞、马超、黄忠

> 状态：可玩机制原型 v0.1  
> 目标：让三名武将与赵云、关羽形成明确的战术分工；数值等待实机平衡。

## 张飞：近战震退

张飞承担“正面顶住、清开包围”的职责，不以位移绕后为核心。

| 模块 | 原型机制 |
|---|---|
| 普攻 | 丈八三式：蛇矛横扫、横矛断阵、燕人震退。末段覆盖大扇面，提供最强普通兵击退。 |
| 被动 | 燕人怒势：累计击杀 6 名敌军后进入 3 秒怒势，获得 18% 减伤。 |
| 主动 | 据水断桥：起手后保留一次约 0.7 秒的全来源格挡，并对正面大范围喝退。 |
| 无双 | 当阳怒吼：横断、震地、断喝三段大范围攻击，突出清场和架势压制。 |

张飞不具备赵云、马超式连续位移；他的安全来自宽范围击退、一次格挡和更高基础防御。

## 马超：冲锋穿阵

马超的核心是“奔势”，强调路径规划和持续前进，而非短距离反复折返。

| 模块 | 原型机制 |
|---|---|
| 被动 | 同方向持续移动积累 0 至 1 的奔势；停步会衰减，急转会显著损失。奔势强化冲阵距离、伤害和击退。 |
| 普攻 | 西凉连骑：银枪点阵、流星横挑、踏阵突刺。第三段随奔势进行平移突刺。 |
| 主动 | 西凉破阵：长距离平移穿阵，命中路径敌军，不使用闪现。 |
| 无双 | 银枪奔雷：连续五段长距离冲锋，每段仅允许有限转角修正。 |
| 视觉 | 只使用人形残影、枪影与尘迹表现冲势，不使用马匹模型或坐骑单位。 |

马超在满奔势时最强，但需要预先跑出路线；被围停住和频繁折返都会削弱他的优势。

## 黄忠：弓刀切换

黄忠是唯一具备独立武器形态切换的英雄。右侧技能区上方提供小型“弓/刀”按钮，键盘原型使用 `R`。

| 模块 | 弓形态 | 刀形态 |
|---|---|---|
| 普攻 | 八方向连珠箭与蓄力穿云，长距离贯穿。 | 断弦横斩、回身断阵，近身范围小但击退明确。 |
| 主动 | 贯星矢：高穿透、长距离重箭。 | 返弦斩：近身清开正面，并在命中帧后自动恢复弓形态。 |
| 无双 | 定军连珠：朝指定方向连续射出五支重箭，重点压制精英和 Boss。 | 同左，维持无双规则一致。 |

切换只允许在未攻击、未位移、未发动无双时执行，避免取消攻击动作。刀形态不是高伤输出模式，而是黄忠被近身时的脱围工具。

## 共用规则

- 三名英雄均使用 `HeroActor` 共用接口，因此可继承暂停、受击白闪、无双、精英/Boss 架势、拼刀、战斗 HUD 与音频反馈。
- 这轮先以代码绘制的像素化占位模型验证招式节奏；正式立绘、待机、移动、攻击与无双素材接入后，只替换表现层，不改变战斗接口。
- 三人的战法树当前均以基础强化池形式开放，后续再按正式素材和实测结果扩展稀有分支。
