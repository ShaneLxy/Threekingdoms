# 战斗与成长规则

> 状态：原型规则 v0.1  
> 适用范围：赵云、长坂坡剧情关与首个无尽模式原型。  
> 数值说明：本文所有数值都是首次可玩原型的起点，必须通过真机手感与性能测试调整。

## 设计目标

1. 保持“手动攻击、主动破阵”的核心，不把普攻退化为自动攻击。
2. 在横屏手机上让移动、瞄准与技能操作同时可用，且不造成连续点击疲劳。
3. 让玩家在 10 分钟剧情关中完成约 7 至 9 次升级，形成能被感知的赵云构筑差异。
4. 让无双在关键军阵阶段首次充满，成为破围高光而不是开场即用的普通技能。

## 一、移动端输入与战斗 UI

### 屏幕布局草图

```text
┌──────────────────────────────────────────────────────┐
│ 暂停    等级 / 经验进度        剧情目标       计时器  │
│                                                      │
│                 俯视斜角战场                         │
│                                                      │
│   [移动摇杆]                       [普攻] [主动]      │
│                                           [无双]      │
└──────────────────────────────────────────────────────┘
```

- 左下：移动虚拟摇杆，始终控制赵云移动。
- 右下：普攻、主动、无双三个按钮；普攻按钮最大，主动与无双围绕其布置。
- 顶部：保留生命、经验、计时、当前剧情目标与敌将状态栏。小兵不显示常驻血条，精英与 Boss 使用固定状态栏，不显示头顶血条。

### 普攻输入规则

| 操作 | 结果 |
|---|---|
| 点击普攻按钮 | 朝上一次攻击方向施放下一段普攻。若没有攻击方向，则朝角色面朝方向施放。 |
| 从普攻按钮向任意方向拖拽后松开 | 朝拖拽方向施放下一段普攻。 |
| 在连招窗口内再次点击或拖拽 | 衔接下一段；默认三段连招。取得“哪吒火轮”且龙胆激活时，第三段结束自动接第四段。 |
| 按住普攻按钮 | **不会持续自动攻击**；松开时只触发一次当前普攻。 |

### 方向辅助与输入缓冲

- 当拖拽方向前方 35° 扇形、攻击范围内存在敌军时，攻击方向最多向最近目标轻微修正 18°。
- 辅助只修正已发出的玩家输入，不会自动索敌、自动出招或跨越明显的兵线。
- 每次普攻允许缓存一次下一段输入，避免玩家因动画前后摇丢失连招。
- 普攻与主动技能均有前摇、有效命中帧与后摇。招式锁定期间不可用摇杆常规移动；第三段、七探盘蛇和无双仅按各自的招式位移移动。
- 每次普攻允许缓存一次下一段输入，输入在当前动作结束时自动衔接；不允许用新的普攻随时取消当前招式。

### 技能输入规则

- 主动技能按钮支持点击和拖拽定向。点击时沿最后一次有效攻击方向释放；拖拽时以拖拽方向为准。
- 无双“七进七出”按七段“突进 / 短暂停顿”执行；每段开始均读取左侧移动摇杆的 8 向输入，摇杆中立时沿上一段方向继续。
- **已定：首个版本不设置独立闪避按钮。**赵云通过持续移动、普攻第三段、主动技能和无双脱离危险区；Boss 红圈的前摇、范围与伤害必须服从这一前提。

## 二、基础战斗属性

首个原型只保留必要属性，避免过早堆叠元素、攻速、吸血、异常状态等难以平衡的系统。

| 属性 | 含义 | 首个版本用途 |
|---|---|---|
| 生命 | 归零即本局失败 | 承担容错与敌军压迫。 |
| 攻击 | 伤害计算的基础值 | 影响普攻和技能。 |
| 护甲 | 按公式降低所受伤害 | 区分轻甲、重甲与敌将。 |
| 移速 | 单位时间移动距离 | 决定走位、拉怪与破阵能力。 |
| 暴击率 / 暴击伤害 | 随机爆发能力 | 作为后续通用强化方向，首版保持简单。 |
| 穿透 | 一次攻击可命中的额外目标数 | 赵云和长枪类英雄的关键属性。 |
| 击退 | 命中后推开普通敌兵的强度 | 用于制造兵海中的暂时空间。 |

### 伤害与防御公式

```text
原始伤害 = 攻击 × 动作倍率 × (1 + 伤害加成)
暴击伤害 = 原始伤害 × 暴击倍率（未暴击时为 1）
最终伤害 = 暴击伤害 × 100 / (100 + 目标护甲)
```

- 首个版本默认暴击倍率为 1.5。
- 护体优先抵消伤害，再扣除生命；“抵消一次普通伤害”的护体不抵消 Boss 的特殊处决类攻击。
- 盾兵正面格挡在护甲计算后额外减伤；背后与侧面不触发该效果。
- 最终伤害最少为 1，避免高护甲导致完全无效的攻击反馈。

### 敌兵行为边界

- 刀兵、戟兵、枪兵、弓兵、弩兵、军旗兵、轻骑斥候、盾兵的行为必须保持可批量模拟；不用每名小兵都配置复杂状态机或路径寻路。
- 基础敌兵攻击均应提供清晰前摇与预警：刀/盾兵至少 0.60 秒、戟兵至少 0.75 秒、弓兵至少 0.85 秒；新刷出的敌军至少经过 1.2 秒才允许首次攻击。
- 弩兵采用固定直线预警，齐射使用错峰的紫色预警；军旗兵只提供可见的范围增益与军令波纹，不制造伤害预警。轻骑斥候的短刺使用橙色预警，冲锋在 0.40 秒驻马前摇后沿水平路线可见平移，并可被对应类型的拼刀中断。
- 敌军死亡时，其未生效攻击必须立即取消，绝不允许出现“尸体攻击”。同一时刻默认最多保留 1 个贴身、1 个戟兵和 2 个弓兵预警，其他单位继续围堵与等待攻击机会。
- 同屏敌军压力由兵种组合、进攻方向与军阵形成，而非仅靠提高单体伤害。

## 五、经验、三选一与无双能量

### 经验与等级

- 剧情原型从等级 1 开始，等级上限暂定为 10。
- 通关时目标等级为 8 至 10；即玩家获得 7 至 9 次强化选择。
- 升级需求采用渐增曲线：`下一等级经验 = 向上取整(12 × 1.28^(当前等级 - 1))`。
- 刀兵、弓兵提供 1 点经验；戟兵、盾兵提供 2 点；精英提供 22 点。Boss 奖励用于结算，不依赖其经验决定胜负。

### 经验掉落表现与性能约束

- 小兵死亡时可显示短暂战魂光点，但逻辑上应合并为经验包；避免在兵海中生成海量独立掉落物。
- 玩家走入拾取半径即可收集经验包；首版不做自动吸附全屏收取。
- 精英必定掉落高价值经验包和无双能量，强化战斗目标感。

### 三选一规则

| 规则 | 原型定义 |
|---|---|
| 每次升级 | 从当前可用强化池抽取 3 项不同选项，暂停战斗供玩家选择。 |
| 早期保底 | 前两次升级各提供一项枪法、一项龙胆和一项主动技能强化，确保玩家早期能主动选择构筑方向。 |
| 可叠加强化 | 单纯数值型强化最多叠加 3 次。 |
| 唯一强化 | 改变机制的强化最多选择 1 次。 |
| 重掷 | 首个版本不提供；先验证原始随机性和池子质量。 |
| 稀有度 | 首个版本不引入多档稀有度，避免掩盖基础平衡问题。 |

升级卡必须显示“分类 · 名称”和一行可量化的效果描述；不能只显示诗意名称，让玩家无法判断选择结果。

### 无双能量

- 无双能量范围为 0 至 100。
- 默认每次发动无双消耗 **40 能量**；关羽“武圣”消耗 **60 能量**。能量达到当前英雄的消耗阈值即可释放，100 能量时仍按当前英雄阈值计算可用次数。
- 击杀普通兵获得 0.3 能量；击杀戟兵或盾兵获得 0.6；击败精英获得 20。
- 对 Boss 的非无双有效伤害按每 50 点伤害转化为 1 点能量，每个阶段最多转化 10 点；Boss 进入第二、三阶段时额外各给 5 点能量。无双伤害不参与转化，不通过“挨打”充能。
- 设计校准目标：正常构筑下，第一次无双应在剧情关 3 至 4 分钟开始可用；高压军阵与 Boss 战中通常可使用 2 至 3 次。
- HUD 始终显示“无双 n / 100”能量条；能量达到 40 时弹出“无双已就绪”，无双键金色呼吸高亮、赵云出现光环。能量不足时按键会显示距 40 的当前进度。

### 命中确认与受击

- 普通刀兵、戟兵、枪兵与弓兵受击时短暂硬直、闪白并按受击方向击退；盾兵减免击退，精英与敌将只产生极短反馈，保持军阵压力。
- 命中至少一个目标时触发约 0.035 至 0.065 秒的短暂停帧；重招额外使用更强的枪影、命中火花和微震。暂停仅用于确认命中，不能打断输入缓存或招式状态。
- “七探盘蛇”命中后提供短暂的低速移动恢复与一次“破阵护体”：只能抵消一次普通敌军攻击，不能抵消 Boss 攻击。它让主动技能成为开阵和脱围工具，而非突入兵堆的自杀按钮。

### 账号军略

- 军需商店的“军略”是账号永久成长，所有可玩英雄与战斗模式生效，不占用局内“临阵抉择”的三选一机会。
- 军略分为军械营、兵甲营、行军营、军令营四支路线，每营四个节点；节点可分阶购买，最终允许全部研习，不设置互斥流派或重置成本。
- 军械营强化攻击、精英/Boss输出与穿透；兵甲营强化生命、护甲、护体和精英/Boss后的回复；行军营强化移速、掉落吸引、升级回复与军功收益；军令营强化主动冷却、无双能量与开局资源。
- 永久数值必须设置上限，避免军略抹平英雄差异。主动冷却先应用军略，再应用英雄专属强化；关羽武圣最终仍受 3.5 秒冷却下限约束。

## 六、难度增长模型

### 当前 3 分钟 Demo 节奏

- 0–25 秒只刷刀兵；25–50 秒加入弓兵；50–75 秒转为盾弓阵；75–100 秒为戟卫夹击与精英；之后由夏侯恩、淳于导逐步压迫，张郃作为收束 Boss 出场。
- 各阶段保留独立的敌军数量上限与刷怪间隔，避免把难度增长简单等同于无限提高单位数量。
- 这套压缩节奏仅用于玩法验证；正式剧情模式仍按 10 分钟章节节奏配置。

### 剧情模式：固定叙事节奏

剧情关通过预设遭遇组织难度，不用纯随机数值压制。长坂坡每两分钟提高一次战场威胁：

| 时间 | 威胁等级 | 重点 |
|---|---:|---|
| 0–2 分钟 | 1.0 | 刀兵教学，少量弓兵。 |
| 2–4 分钟 | 1.6 | 引入盾兵、戟兵与小型盾弓阵。 |
| 4–6 分钟 | 2.2 | 夏侯恩、淳于导具名精英，测试第一轮构筑。 |
| 6–8 分钟 | 3.0 | 混合军阵与多方向夹击。 |
| 8–10 分钟 | 3.6 | 敌将 Boss 与护卫组合。 |

威胁等级是刷怪预算与兵种复杂度的相对倍率，不直接等同于某个固定敌军数量；实际数量必须服从设备性能上限。

### 无尽模式：动态预算

无尽模式共 20 分钟，以“时间 × 威胁预算 × 敌军权重”生成遭遇：

- 0–5 分钟：散兵与单一兵种，建立基础构筑。
- 5–10 分钟：加入盾弓阵、戟卫夹击与第一批精英。
- 10–15 分钟：提高混合兵种比例与精英频率，要求玩家完成破阵强化。
- 15–20 分钟：多方向压力、完整军阵与敌将轮换出现。

无尽模式的敌军密度和视觉表现可按设备动态降级，但同一难度下的威胁预算、经验收益与战斗结算应尽量保持一致。

## 七、首轮验证清单

1. 玩家能在 30 秒内理解“移动摇杆 + 普攻点击/拖拽”的操作，不依赖长篇教学。
2. 连续 3 分钟手动普攻不会造成明显手指疲劳或频繁误触。
3. 赵云在盾弓阵中能通过第三段和七探盘蛇制造可见突破口，但不能无脑穿过所有敌军。
4. 10 分钟内的升级次数与三选一结果能让不同玩家形成明显的打法差异。
5. 无双第一次充满的时点接近 6 至 8 分钟，且玩家愿意留给高压军阵使用。
6. 在目标移动设备上，敌军密度、经验掉落和特效不会造成明显掉帧或发热。

## 八、待验证决策

- 普攻“点击或拖拽后松开”的节奏是否比独立右摇杆更舒适。
- 赵云基础生命与刀兵伤害是否能同时保证容错与压迫感。
- 10 级上限与 12 项强化池是否足够支撑剧情关的构筑差异。
- 无尽模式 20 分钟后采用 Boss 结算还是继续挑战。
